# Editor 개편에서 기존 Project·Stage 하위 호환성 제외

Status: Accepted

Decision: Editor 개편은 현재 존재하는 Project와 Stage의 하위 호환성을 요구하지 않는다. 새 제작 흐름에 필요한 데이터 형식과 실행 계약 변경을 허용하며, 기존 콘텐츠를 위한 호환 계층이나 자동 마이그레이션은 구현하지 않는다. 이 결정은 기존 콘텐츠의 임의 삭제를 의미하지 않으며, 기존 ADR의 모듈 경계와 책임 소유 원칙은 유지한다.

Reason: 기존 콘텐츠와의 호환성 유지가 Actor 편집, 비주얼 스크립팅과 새 Stage 제작 흐름의 설계를 제약하거나 불필요한 구현을 늘리지 않도록 하기 위해서다.
